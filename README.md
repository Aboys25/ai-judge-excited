A pure-Python program that draws a glowing impossible triangle fracturing with light. No image files and no dependencies: every pixel is computed procedurally and the PNG is encoded with the standard library alone, byte-identically on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
